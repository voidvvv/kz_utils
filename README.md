## KZ_UTILS
KZ_UTILS is a collection of utilities designed to enhance the functionality of KZ (Kubernetes Zero) projects. It provides various tools and libraries to streamline development, deployment, and management of Kubernetes applications.

kz_web: is a web application that serves as a API and some server implementation. such as my online blog.
kz_auth_spring_starter: is a Spring Boot starter that simplifies the integration of authentication and authorization features in KZ projects.
sql: is a collection of SQL scripts and utilities for managing databases used in KZ projects.
